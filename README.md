# TeamTrading (팀트)

스포츠 구단을 무료 포인트로 사고파는 모의투자 서비스. 유저끼리 호가창에서 매매하는 HTS 경험을 목표로 한다.

## 첫 버전 범위

- 구단 시세 목록, 차트, 10단계 호가창, 지정가·시장가 주문, 체결 내역
- 포트폴리오, 수익률 랭킹, 종목토론방, 경기 결과 배당(목업)
- 이상거래 방지: 가격제한폭 ±30%, KRX식 호가단위, 자기매매 방지, 익명 호가, 가격 괴리·반복 상대 체결 탐지

서버 없이 브라우저 안에서 동작하며, 다른 유저는 시뮬레이션 계정이다. 포인트는 무료이고 환전·전송이 불가하다.

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm test        # 매칭 엔진 테스트
npm run build   # dist/index.html 한 파일로 빌드
```

## 구조

- `src/engine/orderbook.ts` 가격-시간 우선 매칭 엔진 (순수 함수, 서버 이전 대상)
- `src/engine/fds.ts` 이상거래 탐지
- `src/store.ts` 계좌 처리와 시뮬레이션 유저
- `src/pages/` 화면
