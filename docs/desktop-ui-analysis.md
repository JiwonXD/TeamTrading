# PC 화면 분석과 설계

팬차트 PC(1024px 이상) 화면을 만들기 전에 정리한 레퍼런스 분석과, 그 분석이 어떤 구현으로 이어졌는지 적는다.

- 1차 자료: 사용자가 직접 녹화한 토스증권 웹 사용 영상(102초, 1920×1080, 30fps). 1초 간격 103장과 화면 전환·마우스 이동 구간(9~10초, 43~46초)을 5fps로 잘라서 봤다.
- 2차 자료: 업비트, 바이낸스, 키움(영웅문), 빗썸의 공개 웹 거래 화면. 작업 환경에서 이 사이트들에 직접 접속이 막혀(프록시 터널 실패) 스크린샷을 새로 뜨지 못했다. 그래서 공개적으로 알려진 화면 구성과 동작을 기준으로 정리했고, 토스증권 영상에서 확인한 내용과 구분해서 적는다.

## 1. 토스증권 웹 (영상에서 확인)

### 1.1 전체 틀

| 영역 | 내용 |
| --- | --- |
| 위 메뉴(높이 약 64px, 흰 바탕) | 로고 · 홈 · 피드 · 주식 골라보기 · 내 계좌 · 오른쪽에 검색창("/ 를 눌러 검색하세요") · 로그인 버튼 |
| 본문 | 가운데. 화면마다 패널(흰 카드, 둥근 모서리 16px 안팎) 여러 개를 회색 바탕 위에 배치 |
| 오른쪽 목록(약 300px) | "관심" / "실시간" 종목 목록. 순위 · 로고 · 이름 · 현재가 · 등락. 맨 위 `>>`로 접기, 그 옆 세로 아이콘 줄(내 투자 · 관심 · 최근 본 · 실시간) |
| 아래 띠(약 32px) | 주요 지수(코스피, 나스닥, 달러 환율 등)가 한 줄로 계속 보임. 왼쪽 끝 "투자 유의사항" |

화면을 바꿔도 위 메뉴 · 오른쪽 목록 · 아래 띠는 그대로고 본문만 바뀐다. 종목을 옮겨 다녀도 오른쪽 목록이 계속 보여서 "보면서 고르는" 흐름이 끊기지 않는다.

### 1.2 홈

- 맨 위: 지수 카드 8개(작은 선 차트 + 값 + 등락). 마우스를 올린 카드는 옅은 배경색이 깔린다.
- 가운데: "실시간 차트" 표. 순위 · 하트 · 로고 · 이름 · 현재가 · 등락률 · 거래대금 · 시가총액 · 거래 비율 막대 · 산업 · AI 요약. 표 위에 알약 모양 탭(전체/국내/해외, 거래대금/거래량/급상승/급하락)과 "실시간" 선택.
- 표 오른쪽: 미리보기 패널. **표의 줄에 마우스를 올리면 그 종목의 차트와 "왜 떨어졌을까?" 설명으로 바로 바뀐다.** 클릭하지 않아도 훑어볼 수 있는 구조다(43~46초 구간에서 마우스가 줄을 따라 내려가는 동안 줄 배경과 오른쪽 미리보기가 같이 바뀌는 것을 확인).
- 줄 전체가 클릭 영역이고, 마우스를 올리면 줄 전체에 옅은 회색 배경이 깔린다. 커서는 손가락 모양.

### 1.3 검색

- 위 메뉴의 검색창을 누르거나 `/` 키를 누르면 화면 위쪽 가운데에 큰 검색 창이 뜨고 나머지는 어둡게 덮인다.
- 입력 전: 최근 검색, 실시간 인기 검색어(순위 · 등락).
- 입력 중: 탭(전체/종목/산업/뉴스/지수), 결과 목록에서 **찾은 글자를 파란색으로 강조**, 오른쪽에 관련 소식 · ETF.
- 마우스를 올리거나 방향키로 고른 줄은 회색 둥근 배경 + 오른쪽 끝에 `↵` 표시.
- 아래 줄에 단축키 안내: `ESC 지우기`, `↑ ↓ 탐색`.

### 1.4 종목 주문 화면 (차트 · 호가)

- 맨 위 머리: 로고 · 이름 · 종목코드 · 현재가(크게) · "어제보다 −2,416원(0.52%)" · 오른쪽에 1일 범위 / 52주 범위(**저가~고가 막대 위에 현재가 점**) · 거래대금 · 체결강도 · 시가총액.
- 탭: 차트·호가 / 종목정보 / 뉴스·공시 / 커뮤니티. 선택한 탭은 흰 알약 배경.
- 패널 배치(1920px):
  - 왼쪽 위: 차트(가장 넓음). 기간(1분/일/주/월/년), 보조지표, 전체화면.
  - 가운데: 호가(로그인 전엔 "호가를 보려면 로그인이 필요해요").
  - 오른쪽: 주문(일반주문). 주문 유형 → 수량/소수점 → 지정가/시장가(분할 버튼) → 가격 입력 + `−` `+` → 수량 입력 + `−` `+` → 10% 25% 50% 최대 → 총 주문 금액 → 빨간 큰 버튼.
  - 아래 줄: 커뮤니티 · 시세(실시간 체결) · 개인/외국인/기관.
  - 각 패널 왼쪽 위 `⠿` 손잡이와 `+`로 패널을 옮기거나 탭을 더할 수 있고 "패널 편집"이 있다.
- 차트를 전체화면으로 열면(50~85초) 오른쪽 목록은 남고 차트만 커진다. 마우스를 올리면 **십자선 + 왼쪽·오른쪽 축에 그 위치 가격 표 + 아래 축에 시각 표**가 따라다닌다.
- 차트에서 **오른쪽 클릭하면 "1,078,000원에 구매하기 / 조건 구매하기 / 알림받기 / 선긋기" 메뉴**가 그 가격으로 뜬다(77~85초). 고른 가격에 파란 가로선이 그어진다.

### 1.5 움직임과 반응

| 동작 | 관찰 |
| --- | --- |
| 화면 전환 | 홈 → 종목: 본문이 비었다가 패널 틀이 먼저 그려지고 내용이 채워진다(9.5~10.5초). 위 메뉴와 오른쪽 목록은 깜빡이지 않는다. |
| 마우스 올림 | 줄·카드·탭에 옅은 배경색. 테두리나 그림자는 거의 쓰지 않는다. 전환은 짧아서(한두 프레임) 거의 즉시 바뀌는 느낌. |
| 안내 말풍선 | 새 기능은 파란 말풍선(흰 글자, 닫기 ×, "확인")으로 패널 옆에 붙는다. |
| 프로필 위에 마우스 | 커뮤니티 글쓴이 위에 올리면 QR 카드가 작은 팝업으로 뜬다. |
| 커서 | 클릭할 수 있는 줄·버튼은 손가락, 차트 위는 십자 모양. |

## 2. 다른 거래 화면 (공개 화면 기준)

| 사이트 | 배치 | 가져올 점 |
| --- | --- | --- |
| 업비트 웹 거래소 | 왼쪽 큰 영역: 위 차트, 아래 호가 + 주문창 + 체결. 오른쪽: 코인 목록(검색, 원화/BTC/USDT 탭, 현재가·전일대비·거래대금 정렬). | **시세가 바뀐 칸에 잠깐 빨강(상승)·파랑(하락) 테두리가 켜졌다 사라지는 깜빡임.** 호가를 누르면 주문창 가격이 채워진다. 목록 헤더를 눌러 정렬. 한국식 상승 빨강/하락 파랑. |
| 바이낸스 현물 | 3열 고밀도: 왼쪽 호가, 가운데 차트 + 아래 주문창, 오른쪽 종목 목록 + 최근 체결. 다크가 기본. | 호가 줄마다 **잔량 막대(깊이)**, 마우스를 올린 호가까지의 누적 수량·평균가 툴팁, 현재가 줄 강조, 키보드 단축키. |
| 키움 영웅문(HTS/웹) | 여러 창(현재가, 호가, 주문, 체결, 관심종목)을 한 화면에 띄우고 사용자가 배치. | 정보 밀도가 높다. 숫자는 고정폭 숫자 정렬. 호가창 클릭 주문. |
| 빗썸 웹 | 업비트와 비슷한 2열(왼쪽 차트·호가·주문, 오른쪽 목록). | 주문창 위 구매/판매 탭을 빨강/파랑으로 나눔. |

공통점: (1) **종목 목록은 항상 옆에 보인다**, (2) **차트 · 호가 · 주문을 한 화면에 동시에** 둔다, (3) **호가 클릭 = 주문 가격 채우기**, (4) 바뀐 시세를 순간적으로 강조한다, (5) 숫자는 오른쪽 정렬 + 고정폭.

## 4. 반응형 기준

- 1024px 미만: 기존 모바일 화면(아래 탭바, 주문 시트). 바뀐 것 없음.
- 1024px 이상: PC 셸. `useDesktop()`이 `matchMedia('(min-width: 1024px)')`를 구독해 창 크기를 바꾸면 바로 바뀐다.
- PC 안에서는 **본문 폭(컨테이너 쿼리)** 기준으로 열을 줄인다. 오른쪽 목록을 접고 펴면 본문 폭이 바뀌기 때문이다.
  - 본문 1180px 초과: 구단 화면 3열, 홈 표 + 미리보기.
  - 본문 1180px 이하: 구단 화면은 차트 전체 폭 + 호가·주문 2열, 홈 미리보기 숨김.
  - 본문 860px 이하: 홈 위 카드 1열, 표의 범위 열 숨김.
- 동작 줄이기 설정(`prefers-reduced-motion`)이면 애니메이션·전환을 끈다.
- 다크 모드는 기존 색 토큰을 그대로 따르고, 빨강·파랑 바탕 위 글자만 `--on-accent`로 대비를 맞췄다.

## 5. 확인

- 스크린샷: 1600×960(홈·검색·구단·내 투자), 1280×800(구단, 좁은 배치), 1440×900 다크(구단, 목록 접음), 390×844(모바일 홈, 변화 없음).
- 접근성: axe 위반 0건(라이트·다크 × 홈·구단·내 투자·랭킹·시장감시·검색창).
- E2E: `desktop` 프로젝트(1440×900) 3건 — 홈 표 18줄과 구단 목록 18줄, `/` 검색 후 Enter로 구단 이동, 판매 호가 클릭 → 주문창 가격·방향 채움 → 1주 구매.
