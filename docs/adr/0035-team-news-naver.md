# 0035. 구단 뉴스는 네이버 검색 API(뉴스)로 받아 서버가 구단별로 모아 둔다

- 상태: 채택
- 날짜: 2026-11-08

## 배경

부상·이적·일정 같은 구단 소식은 매수 판단에 직접 영향을 준다. 토스증권의 "뉴스·공시" 탭처럼 구단 화면에서 최신 기사를 보고 싶다. 무료로 쓸 수 있고 한국 언론사 기사가 나오는 출처가 필요하다.

## 결정

- **출처는 네이버 검색 API 뉴스**(`https://openapi.naver.com/v1/search/news.json`). 키는 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`. 키가 없으면 `available: false`로 답하고 화면은 "준비 중"을 보인다.
- **검색어는 "구단 이름 + 종목"**(`T1 롤`, `LG 트윈스 야구`, `브렌트퍼드 축구`). 이름만 찾으면 T1·KT처럼 다른 뜻이 섞인다. 최신순 20개.
- **서버가 구단별로 15분 모아 두고 모든 이용자가 같이 쓴다.** 140개 구단을 계속 본다고 해도 하루 13,440회로 무료 한도(25,000회) 안이다. 다시 받다 실패하면 이전 결과를 그대로 보여주고, 이전 결과도 없으면 503.
- **기사 제목·요약의 강조 태그(`<b>`)를 빼고 HTML 문자 참조를 글자로 돌려** 화면에는 글자만 보낸다(화면이 HTML로 넣지 않는다). 원문 주소(`originallink`)가 있으면 언론사로, 없으면 네이버 뉴스로 잇는다. 언론사 이름은 API가 주지 않아 주소의 호스트를 보인다.
- 화면: PC `차트 · 호가 | 구단정보 | 뉴스 · 공시 | 토론`, 모바일 `… | 정보 | 뉴스·공시 | 토론`. 탭 안에서 뉴스·공시를 고른다(뉴스 먼저).

## 이유

- 한국어 기사, 무료 한도, 검수 없음(애플리케이션 등록에서 "검색" API를 고르면 바로 키가 나온다)이 모두 맞는다.
- 이용자가 화면을 열 때마다 부르면 한도를 넘을 수 있고 응답도 느리다. 기사는 몇 분 늦어도 문제가 없어 서버에서 모아 두는 편이 낫다.

## 검토한 대안

- **NewsAPI.org:** 무료 요금제는 개발용(운영 금지)이고 한국 기사가 적다.
- **구글 뉴스 RSS:** 공식 API가 아니고 이용 조건이 분명하지 않다.
- **GNews 등 해외 뉴스 API:** 무료 한도가 하루 100회 안팎이고 한국 기사가 적다.
- **언론사 RSS를 직접 모으기:** 구단별로 거르기 어렵고 언론사마다 형식이 다르다.
- **기사 사진(썸네일):** 검색 API가 주지 않는다. 기사 페이지를 긁어 오면 저작권·트래픽 문제가 있어 넣지 않는다.
