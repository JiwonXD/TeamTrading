# 0017. 광고 보상은 광고 네트워크의 서명된 서버 콜백으로만 준다

- 상태: 채택
- 날짜: 2026-11-02

## 배경

광고를 끝까지 보면 1,000P(하루 10회)를 준다. 앱이 "다 봤어요"라고 알리는 방식은 요청을 꾸며 보내기만 해도 포인트가 생긴다. 포인트는 가상이어도 발행 통제가 깨지면 리더보드와 대사가 의미를 잃는다(0008).

## 결정

- **광고 세션.** 앱은 광고를 띄우기 전에 `POST /api/accounts/me/ads`로 세션을 연다. 세션 id를 광고 SDK의 `custom_data`로 넘긴다. 계정 id는 내보내지 않는다.
  - 세션은 1시간 안에 완료돼야 하고, 계정당 하루 50개까지 연다. 오늘 한도(10회)를 다 받았으면 새로 열 수 없다.
- **서버 측 검증(SSV) 콜백.** AdMob이 `GET /api/ads/admob/callback`으로 보내는 콜백만 지급 근거로 쓴다.
  - 받은 그대로의 쿼리 문자열에서 `&signature=` 앞까지를 구글 공개키(ECDSA P-256, SHA-256)로 검증한다. 키는 구글이 공개하는 목록에서 받아 두고, 모르는 `key_id`가 오면 1분에 한 번까지만 다시 받는다.
  - 서명이 맞아도 등록한 광고 단위(`fanchart.ads.admob-ad-units`)가 아니면 거절한다. 다른 앱이 우리 콜백 주소를 써도 구글 서명은 맞기 때문이다. 목록이 비어 있으면 모든 콜백을 거절한다.
- **한 번만 완료.** 세션 행을 잠그고 PENDING일 때만 지급한다.
  - 같은 거래 id로 다시 오면(네트워크 재시도) 처음 결과를 200으로 돌려준다. 다른 거래 id면 409로 거절한다.
  - 지급은 `PointIssuer.grantWithinLimit(AD_VIEW, "admob:거래 id")`라 발행 멱등키와 하루 한도를 그대로 따른다. 한도를 넘긴 콜백은 LIMIT로 끝내고 지급하지 않는다.
- **시연 서버.** demo 프로필(`fanchart.ads.demo`)은 광고 네트워크 없이 세션을 열고 15초가 지나면 지급하는 가짜 광고를 연다. 서버 시계로 시간을 확인한다. 운영 설정에서는 404다.

## 검토한 대안

- **앱의 완료 신호로 지급:** 요청 위조로 포인트를 만든다.
- **콜백의 `user_id`로 계정 구분:** 계정 id를 앱과 광고 회사에 노출해야 한다. 한 번 쓰는 세션 id가 더 좁다.
- **웹 광고(AdSense 등):** 보상형 광고와 서버 검증 콜백이 없다. 웹은 시연용만 두고 실제 광고는 앱(M7)에서 연다.

## 결과

- 실제 광고는 앱 출시(M7, Capacitor + AdMob) 때 광고 단위 id와 콜백 주소를 등록하면 켜진다.
- 위조 콜백은 403과 경고 로그로 남는다. 반복되면 경보 규칙을 추가한다.
