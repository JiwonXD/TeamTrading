# 0026. 시장감시(이상거래 탐지 기록)는 운영자만 본다

- 상태: 채택
- 날짜: 2026-11-07

## 배경

이상거래 탐지(FDS, ADR 0021)는 가격 괴리와 반복 상대 체결을 기록한다. 지금까지 `GET /api/surveillance/alerts`는 로그인 없이 누구나 부를 수 있었고, 화면 아래 탭의 "시장감시"도 모든 유저에게 보였다. 계정 id 대신 닉네임만 내보냈지만, 탐지 기록에는 의심 거래 양쪽 닉네임이 들어 있다. 화면 안내에도 "운영자 화면 예시예요. 실제 서비스에서는 일반 유저에게 계정명을 보여주지 않아요"라고 적혀 있어, 공개 상태는 미리보기 때의 설정이 실서비스까지 이어진 것이었다.

## 결정

- ADR 0009에서 "로그인 없이 볼 수 있다"고 정한 것 중 탐지 기록만 바꾼다. 탐지 기록 API를 `/api/surveillance/**` 전체와 함께 `ROLE_ADMIN`만 부를 수 있게 한다(로그인 안 함 401, 일반 계정 403).
- `GET /api/accounts/me` 응답에 `admin`을 더한다. 화면은 이 값으로 시장감시 탭(모바일 아래 탭, PC 위 메뉴)과 `#watch` 주소를 운영자에게만 보인다. 실제 권한 검사는 서버가 하고, 화면 값은 메뉴 표시용이다.
- 일반 계정의 화면은 탐지 기록을 요청하지 않는다(3초 갱신마다 403이 나지 않게).
- 브라우저 시뮬레이션 미리보기는 계정 구분이 없으므로 "운영자 화면 예시"로 그대로 보여준다.

## 이유

- **혐의 확정 전 공개 지목.** 탐지는 의심 신호일 뿐이다. 같은 팀 팬끼리 우연히 여러 번 체결돼도 기록된다. 닉네임을 공개하면 확인되지 않은 혐의로 특정 유저를 지목하게 된다. 증권사·거래소의 시장감시도 내부 업무다.
- **탐지 기준 노출.** 어떤 거래가 기록되는지 실시간으로 보이면, 포인트를 옮기려는 사람이 기록되지 않는 선(횟수·간격·가격 차이)을 맞춰 피해 갈 수 있다.
- 규칙 자체(가격제한폭, 자기매매 방지, 익명 호가)는 약관과 화면 안내로 계속 알린다.

## 검토한 대안

- **닉네임을 가리고 공개(예: "계정 A ↔ 계정 B"):** 지목 문제는 줄지만 탐지 기준 노출은 그대로이고, 일반 유저에게 쓸모가 거의 없다.
- **화면 메뉴만 숨김:** API가 공개면 누구나 직접 부를 수 있어 숨긴 의미가 없다.
