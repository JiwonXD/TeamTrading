# 0029. 홈 리그 탭의 순서와 보일 리그는 계정에 저장한다

- 상태: 채택
- 날짜: 2026-11-07

## 배경

홈 맨 위 리그 탭(전체·KBO·LCK·프리미어리그·라리가·세리에A·분데스리가·K리그)은 모든 사람에게 같은 순서로 다 보였다. 리그가 늘수록(NBA 추가 예정) 탭 줄이 길어지고, 관심 없는 리그가 앞을 차지한다. 사람마다 순서를 바꾸고 원하는 리그만 보이게 하려 한다.

## 결정

- **계정별로 서버에 저장한다.** `account_league_tabs(account_id, league, position, hidden)`. `GET/PUT /api/accounts/me/league-tabs`가 `{ order, hidden }`을 주고받고, 저장은 통째로 바꾼다(계정 행을 잠가 두 기기의 동시 저장이 섞이지 않게).
- **"보일 리그"가 아니라 "숨긴 리그"를 저장한다.** 저장한 뒤 새로 생긴 리그는 순서 목록에 없으므로 화면이 맨 끝에 보이는 상태로 붙인다. 없어진 리그(enum에서 빠진 코드)는 읽을 때 건너뛴다. 탭 정의는 화면의 `LEAGUES`와 서버 `League` enum을 따르므로 리그를 추가할 때 탭 설정 코드는 고치지 않는다.
- **전체 탭은 늘 맨 앞에 있고 숨길 수 없다.** 숨긴 리그도 주소(`#league-…`)로 들어오면 그 탭은 보여 지금 어디 있는지 잃지 않게 한다.
- PC 오른쪽 구단 목록의 리그 거르기 버튼도 같은 순서·숨김을 따른다. 아래 시세 띠와 "전체" 홈의 구단 목록은 그대로 모든 구단을 보인다(설정은 탭 줄을 정리하는 것이지 시장을 가리는 것이 아니다).
- 편집은 아래에서 올라오는 시트에서 체크박스로 켜고 끄고, 위·아래 버튼으로 순서를 바꾼다. 저장을 눌러야 반영된다.
- 탈퇴하면 설정 행도 지운다. 브라우저 시뮬레이션 미리보기는 계정이 없으므로 localStorage에 둔다.

## 이유

- 최종 목표가 웹·PC·모바일 앱(MTS)을 한 계정으로 쓰는 것이라, 기기마다 다시 설정하게 하면 안 된다. 증권 앱의 관심종목·화면 설정도 계정에 붙는다.
- 탭은 리그가 늘어날 때 깨지기 쉬운 곳이다. "보일 리그"를 저장하면 새 리그가 설정한 사람에게 영영 안 보이므로, 기본값이 "보임"이 되도록 숨김을 저장한다.

## 검토한 대안

- **기기별 localStorage:** 서버 작업이 없지만 PC에서 바꾼 순서가 휴대폰에 없고, 앱으로 옮길 때 다시 만들어야 한다.
- **끌어서 순서 바꾸기:** 터치로 익숙하지만 키보드·스크린리더로 쓰기 어렵고, 탭이 열 개 안팎이라 위·아래 버튼으로 충분하다. 리그가 많이 늘면 다시 본다.
- **운영자 전역 기본 순서:** 지금은 `LEAGUES` 배열 순서가 기본 순서 역할을 하므로 따로 두지 않는다.
