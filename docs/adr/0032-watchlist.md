# 0032. 관심 구단은 계정에 저장하고 한 구단씩 넣고 뺀다

- 상태: 채택
- 날짜: 2026-11-07

## 배경

구단이 140개 안팎으로 늘어날 예정이라(전 리그 구단 등록), 거래대금순 목록에서 내가 보는 구단을 매번 찾기 어렵다. 증권 앱의 관심종목처럼 구단을 담아 두고 한곳에서 시세를 보고 싶다.

## 결정

- **계정별로 서버에 저장한다.** `account_watchlist(account_id, team_id, position)`. `GET /api/accounts/me/watchlist`가 `{ teamIds }`를 담은 순서대로 준다.
- **목록을 통째로 바꾸지 않고 한 구단씩 넣고 뺀다.** `PUT`·`DELETE /api/accounts/me/watchlist/{teamId}`. 같은 구단을 다시 넣거나 없는 구단을 빼도 결과가 같아(멱등) 다시 보내도 안전하다. 넣을 때는 계정 행을 잠가 두 기기의 동시 추가가 같은 순번을 갖지 않게 한다.
- **없는 구단은 넣을 수 없고(404), 목록에서 빠진 구단은 읽을 때 건너뛴다.** 구단 수만큼만 담을 수 있으므로 따로 개수 상한을 두지 않는다.
- **화면은 먼저 바꾸고 요청은 누른 순서대로 하나씩 보낸다.** 빠르게 여러 번 눌러도 서버 처리 순서가 누른 순서와 같다. 서버가 돌려준 목록은 보낼 요청이 더 없을 때만 반영해, 아직 보내지 않은 누름이 화면에서 되돌아가지 않게 한다. 실패하면 서버 목록을 다시 받아 맞춘다.
- **별을 두는 곳:** 구단 화면 이름 옆(PC), 구단 화면 위 오른쪽(모바일, 토스증권 관심 버튼 자리), PC 홈 시세 표 각 줄 맨 앞, 관심 목록 각 줄. 눌린 상태는 `aria-pressed`로 알린다.
- **모아 보는 곳:** PC는 오른쪽 구단 목록에 "관심" 탭을 맨 앞에 더한다(담은 순, 리그 거르기 그대로 적용, 줄 앞 별로 바로 빼기). 고르기 전에는 관심 구단이 있으면 관심 탭, 없으면 실시간 탭을 연다. 모바일은 "전체" 홈의 내 자산 바로 아래에 관심 구단 카드를 둔다.
- 탈퇴하면 관심 구단도 지운다. 브라우저 시뮬레이션 미리보기는 localStorage에 둔다.

## 이유

- 리그 탭 설정([0030](0030-league-tab-prefs.md))과 같이, 웹·PC·앱을 한 계정으로 쓰는 목표에 맞춰 계정에 둔다.
- 리그 탭은 편집 시트에서 한 번에 저장하지만 관심 구단은 여기저기서 별 하나씩 누른다. 목록을 통째로 보내면 휴대폰에서 담은 구단을 PC의 오래된 목록이 지워 버린다(마지막 저장이 이기는 덮어쓰기). 한 구단 단위 요청은 서로 다른 구단의 누름이 섞여도 잃는 것이 없다.

## 검토한 대안

- **목록 통째 저장(PUT 전체):** 순서 바꾸기는 쉽지만 위의 덮어쓰기 문제가 있다. 순서 바꾸기가 필요해지면 순서만 따로 바꾸는 요청을 더한다.
- **모든 목록 줄에 별:** PC 오른쪽 실시간·보유 목록과 모바일 구단 시세 목록에도 별을 두면 좁은 목록에서 잘못 누르기 쉽고 줄이 복잡해진다. 표처럼 넓은 곳과 관심 목록에만 둔다.
- **모바일 아래 탭에 "관심" 추가:** 탭이 다섯 개가 되고(운영자는 시장감시 포함) 홈과 내용이 겹친다. 홈 카드로 충분하다.
- **관심 그룹(여러 목록)·알림:** 지금 구단 수와 사용자 수에서는 과하다. 필요해지면 다시 본다.
