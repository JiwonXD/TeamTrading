# 0006. 실시간 시세에 구단별 seq와 epoch

- 상태: 채택
- 날짜: 2026-10-28

## 배경

클라이언트는 스냅숏을 받은 뒤 업데이트를 이어 붙인다. 업데이트가 빠지거나 순서가 바뀌면 화면의 호가가 틀린다.

## 결정

- 구단마다 업데이트에 1씩 늘어나는 `seq`를 붙이고, 서버 기동마다 바뀌는 `epoch`를 함께 보낸다.
- WebSocket 구독 등록과 스냅숏 전송을 종목 락 안에서 함께 해서 스냅숏과 첫 업데이트 사이에 틈이 없게 한다.
- 매 업데이트에 위아래 10단계 호가를 통째로 보낸다 (차분이 아니라).
- 전송은 세션마다 둔 가상 스레드가 하고, 큐(256건)가 넘친 세션은 끊는다.

## 검토한 대안

- 호가 차분만 전송: 데이터는 작지만 하나만 빠져도 화면이 틀어지고 복구 로직이 복잡하다.
- STOMP 메시지 브로커: 토픽 구독은 편하지만 스냅숏과 구독 사이 순서를 보장하기 어렵다.

## 결과

- 클라이언트는 seq가 건너뛰면 다시 접속하기만 하면 된다.
- 업데이트 크기가 호가 깊이에 비례한다. 10단계에서는 문제되지 않는다.
