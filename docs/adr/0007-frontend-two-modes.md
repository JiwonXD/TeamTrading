# 0007. 화면은 서버 모드와 브라우저 시뮬레이션 모드를 함께 둔다

- 상태: 채택
- 날짜: 2026-11-02

## 배경

화면을 백엔드에 연결해야 하지만, 서버 없이 HTML 한 파일로 여는 미리보기도 계속 필요하다. 서버에는 아직 다른 사람이 없어 연결만 하면 호가창이 빈다.

## 결정

- 같은 화면 코드가 저장소 구현 둘 중 하나를 쓴다. `VITE_BACKEND=server`로 빌드하면 서버 모드, 아니면 브라우저 시뮬레이션 모드. 두 구현은 화면이 읽는 상태(`storeTypes.ts`)를 같은 모양으로 채운다.
- 서버 모드는 목록·계좌·랭킹·감시 기록을 3초 주기로 받고, 보고 있는 구단만 WebSocket으로 구독한다.
- 개발·시연 서버는 `demo` 프로필에서 시뮬레이션 계정 20개를 띄운다. 이 계정들은 일반 계정과 똑같이 주문 API로만 거래하며, 시스템 마켓메이커가 아니다.

## 검토한 대안

- 시뮬레이션 모드 삭제: 미리보기 링크가 사라진다.
- 모든 구단을 WebSocket으로 구독: 구단이 18개라 연결이 18개 생긴다. 서버에 여러 구단 구독을 받는 단일 연결을 만들기 전까지는 목록은 주기 조회로 둔다.
- 화면 안에서 봇을 돌려 서버에 주문: 브라우저를 닫으면 시장이 멈추고, 봇 계정 id가 브라우저에 노출된다.

## 결과

- 서버 모드에서 아직 서버에 없는 기능(토론 글 저장, 경기 배당)은 비활성화하거나 브라우저에만 남긴다.
- 화면 변경은 두 모드 모두에서 확인해야 한다. 서버 모드는 Playwright E2E가 CI에서 확인한다.
