# 0033. 받을 경기 데이터가 없는 리그는 설정 한 줄로 닫는다

- 상태: 채택
- 날짜: 2026-11-08

## 배경

첫 실수집에서 KBO와 K리그는 API-Sports 무료 요금제가 2022~2024 시즌만 열려 있어 올해 일정을 받지 못했다. K리그 구단 대회인 코리아컵은 무료 출처가 아예 없다. 일정·배당이 없는 리그가 홈 리그 탭과 구단 목록에 그대로 보이면 사용자는 "왜 경기가 안 뜨냐"고 묻게 되고, 수집은 6시간마다 오류만 남긴다.

## 결정

- **설정 하나로 닫는다.** `fanchart.leagues.hidden`(환경 변수 `HIDDEN_LEAGUES`, 기본 `KBO,K_LEAGUE`).
- **서버:** 닫은 리그의 정규 시즌은 수집하지 않는다(`MatchFeedSync.active`). `GET /api/leagues`가 `{ hidden }`을 준다. 운영자 화면 `GET /api/admin/match-feed`에도 수집 꺼짐으로 보인다.
- **화면:** 시작할 때 `/api/leagues`를 한 번 받아 닫힌 리그를 홈 리그 탭, 전체 홈 구단 목록, PC 오른쪽 실시간 목록, 검색에서 뺀다. 받지 못하면 모든 리그를 보여 준다.
- **구단 자체는 지우지 않는다.** 구단·주문장·잔고는 그대로라 이미 산 주식은 보유·관심 목록과 구단 화면에서 계속 보이고 팔 수 있다.
- **코리아컵은 수집 목록에서 뺐고, ACL은 꺼 둔다.** 둘 다 K리그 구단 대회다. `Competition.KOREA_CUP` 값은 저장된 데이터와 맞추려고 남긴다.
- 다시 열 때는 `.env`에 `HIDDEN_LEAGUES=K_LEAGUE`처럼 남길 리그만 적고 다시 띄운다(KBO만 열기). 빈 값(`HIDDEN_LEAGUES=`)이면 모두 연다.

## 이유

- 3월 KBO 개막 전에 유료 키를 살지 정해야 해서, 코드 수정 없이 다시 열 수 있어야 한다.
- 화면에서만 숨기거나 수집만 끄면 둘이 어긋난다. 한 설정을 서버가 쓰고 화면에 내려 주면 둘이 늘 같다.

## 검토한 대안

- **구단 삭제·상장 폐지:** 이미 산 사람의 주식과 원장이 걸려 있어 되돌리기 어렵다.
- **화면 상수로 숨기기:** 다시 열 때마다 프런트 빌드가 필요하고 서버 수집과 따로 논다.
- **리그 탭 편집(ADR 0030)으로 사용자가 끄게 하기:** 탭만 숨고 홈 구단 목록·검색에는 남는다. 받을 데이터가 없다는 건 사용자 취향이 아니라 운영 사정이다.
