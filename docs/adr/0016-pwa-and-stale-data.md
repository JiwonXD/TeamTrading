# 0016. PWA는 화면 껍데기만 캐시하고, 서버 값이 아니면 그렇다고 알린다

- 상태: 채택
- 날짜: 2026-11-02

## 배경

모바일 앱(MTS)으로 가는 첫 단계로 홈 화면에 설치할 수 있게 한다(PWA). 서비스 워커가 응답을 캐시하면 오프라인에서도 화면이 뜬다. 그런데 시세나 잔고까지 캐시하면 지난 값을 지금 값처럼 보여주게 된다.

점검해 보니 서버 모드 화면에는 이미 같은 문제가 있었다.

- 서버에 닿기 전이나 닿지 못하면 자산 100만P와 구단 기준가를 그대로 보여줬다.
- 첫 연결에 실패하면 다시 시도하지 않았다.
- 서버가 재시작해 세션이 사라지면 갱신이 조용히 멈췄다.

## 결정

- 서비스 워커는 화면 파일, 매니페스트, 아이콘만 캐시한다.
  - `/api`, `/ws`, 소셜 로그인 경로에는 손대지 않는다.
  - 화면 파일은 네트워크를 먼저 보고, 실패할 때만 캐시를 쓴다. 배포하면 다음 접속에 바로 바뀐다.
- 서비스 워커는 서버 모드 배포본에서만 등록한다. 개발 서버와 시뮬레이션 미리보기에서는 등록하지 않는다.
- 화면은 서버에서 받은 값만 보여준다.
  - 한 번도 받지 못했으면 기본값 대신 "연결하는 중", "연결할 수 없어요"만 보여주고, 3초마다 다시 시도한다.
  - 받은 뒤 갱신이 실패하면 "HH:MM:SS 기준 값"이라고 알린다. 브라우저가 오프라인이면 그것도 알린다.
  - 갱신이 401이면(서버 재시작으로 세션이 사라짐) 로그인부터 다시 한다.

## 결과

- Chrome 설치 가능 검사(installability)를 통과한다. 오프라인에서도 화면 껍데기가 뜨고, 그때도 상태 표시가 보인다.
- E2E가 API를 막아 세 상태를 확인한다: 연결 불가 시 기본값 미표시, 재연결, 끊김 표시.
- 오프라인 주문 대기열은 두지 않는다. 연결이 돌아온 뒤 사용자가 다시 주문한다. 의도하지 않은 지연 체결을 막기 위해서다.
