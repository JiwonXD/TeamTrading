# 0027. 경기 데이터 제공처와 키를 리그마다 따로 둔다

- 상태: 채택(0024의 "제공처는 API-Sports 하나, 키 하나"를 대체한다. 동기화 규칙은 0024 그대로)
- 날짜: 2026-11-07

## 배경

리그를 KBO·LCK·프리미어리그·라리가·세리에A·분데스리가(그리고 기존 K리그)로 넓힌다. 0024는 API-Sports 키 하나로 KBO와 K리그를 받았는데, 리그가 늘면 한 제공처로는 부족하다.

- LCK는 API-Sports에 없다.
- 유럽 4대 리그는 API-Sports 무료 요금제가 현재 시즌을 주는지 확인되지 않았다("recent seasons"라고만 적혀 있다). football-data.org 무료 요금제는 네 리그를 모두 주고 하루 상한이 없다(분당 10회).
- 키가 하나면 한 리그 문제(만료, 요금제 변경)로 모든 리그가 멈춘다. 리그를 하나씩 붙여 보며 확인하기도 어렵다.

## 결정

- **리그마다 설정 한 줄.** `fanchart.match-feed.leagues[]`에 리그, 제공처(source), 키, 제공처 리그 번호(문자열: API-Sports 5, football-data PL), 시즌, 주소, 하루 상한을 둔다. 키는 리그별 환경 변수(`KBO_API_KEY`, `LCK_API_KEY`, `EPL_API_KEY`, `LALIGA_API_KEY`, `SERIEA_API_KEY`, `BUNDESLIGA_API_KEY`, `KLEAGUE_API_KEY`)로 받는다.
- **키가 빈 리그만 쉰다.** 나머지 리그는 그대로 수집한다. 운영자는 `GET /api/admin/match-feed`로 리그별 제공처와 수집 여부를 본다. 한 리그는 한 번만 둔다(두 제공처가 같은 경기를 따로 만들지 않도록 기동 때 거절).
- **제공처는 `FeedProvider` 하나로 더한다.** 요청 모양과 응답 해석만 제공처마다 다르고, 응답을 `FeedGame`으로 옮긴 뒤의 동기화 규칙(0024)은 같다. 기본 배치:

  | 리그 | 제공처 | 리그 번호 |
  | --- | --- | --- |
  | KBO | API-Sports API-Baseball | 5 |
  | K리그 | API-Sports API-Football | 292 |
  | LCK | PandaScore | 293 |
  | 프리미어리그·라리가·세리에A·분데스리가 | football-data.org | PL·PD·SA·BL1 |

- **해석 규칙(새 제공처).**
  - football-data: 시작 시각은 `utcDate`. 날짜 조건이 UTC 날짜라서 한국 시간 하루를 덮도록 전날부터 묻는다. 몰수(AWARDED)는 UNKNOWN.
  - PandaScore: 홈·원정은 opponents의 첫째·둘째 팀, 점수는 세트 승수. 시즌 대신 이틀 전부터 45일 뒤까지를 예정 시각 순으로 한 쪽(100경기)만 받는다(새 경기는 시작 36시간 안의 것만 들이므로 지난 경기는 필요 없고, 잘려도 먼 경기부터 빠진다). 몰수(forfeit)는 UNKNOWN.
  - 둘 다 상대가 정해지지 않은 경기(플레이오프 대진 미정)는 건너뛴다. API-Sports는 리그 경기라 늘 팀이 있어 기존대로 응답 전체를 거절한다.
- **요청 상한은 제공처·키마다 센다.** 무료 한도가 키(계정)마다 걸리므로, 같은 football-data 키를 유럽 4개 리그에 넣으면 상한도 함께 쓴다. 기본 상한은 API-Sports 90회, football-data·PandaScore 500회(하루, 한국 시간).
- **키는 로그에 남기지 않는다.** 리그 설정의 문자열 표현에서 키를 뺐다.
- **새 리그 배당.** 승리 배당은 0010 방식(평균 팀의 시즌 승리 배당 총액 약 3,000P)으로 역산했다. 프리미어리그·라리가·세리에A 210P(38경기, 평균 약 14승), 분데스리가 240P(34경기, 평균 약 12.5승).

## 검토한 대안

- **API-Sports 하나로 유럽 리그까지:** 키 하나로 끝나지만 무료 요금제의 현재 시즌 제공 여부가 확인되지 않았다. 설정에서 source만 `api-football`로 바꾸면 그대로 쓸 수 있게 남겨 두었다(이때는 시즌을 시작 연도로 직접 적는다).
- **LCK에 LoL Esports 비공식 API:** 키 발급 없이 되지만 사이트에 박힌 공개 키를 쓰는 비공식 경로라 약관·중단 위험이 있다. PandaScore는 공식 무료 요금제(일정·결과, 시간당 1,000회)가 있다.
- **KBO 공식 사이트 수집:** 0024와 같은 이유(화면 변경 시 조용히 틀린 값, 약관)로 하지 않는다. API-Sports 무료 요금제가 올해 KBO를 막으면 그때 다시 정한다.
- **K리그 탭 제거:** 이미 구단 4개와 경기 기록이 DB에 있어 지우려면 데이터 정리가 필요하다. 리그 하나를 더 둬도 비용이 없어 남긴다.

## 남은 일

- 키를 받은 뒤 리그 번호와 현재 시즌 조회 가능 여부를 확인한다(docs/operations.md "경기 데이터 수집"). 특히 API-Sports 무료 요금제의 2026 KBO 시즌, PandaScore의 LCK 리그 번호(293), PandaScore 무료 요금제에 LoL이 들어가는지.
- 유럽 4대 리그와 LCK 나머지 구단은 아직 등록하지 않았다. 구단 등록과 첫 상장 공모(0019)는 사용자 수를 보고 운영자가 한다. 등록 전에는 그 리그 경기가 "연결하지 않은 팀"으로 동기화 결과에 나온다.
