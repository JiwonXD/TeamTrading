# 레퍼런스: 롤스피(LOLSPI)

롤스피(https://lolspi.com)는 LoL e스포츠 구단을 가상 주식처럼 사고파는 팬 프로젝트다. 팬차트와 컨셉이 가장 가까운 서비스라 기능, 화면, 운영 사례를 정리하고 팬차트와 비교한다.

- 조사일: 2026-11-08. 로그인 없이 볼 수 있는 화면(홈, 리그별 모아보기, 랭킹, 종목 화면, 공지 6건, 랜덤 주식 이벤트, 소개, 투자 유의사항, 이용약관)과 robots.txt, sitemap.xml을 봤다.
- 로그인이 필요한 화면(내 계좌, 알림, 주문 실행, 이벤트 뽑기)은 보지 않았다. 그 부분은 소개 화면과 약관 문구로 추정했고, 추정이라고 표시했다.
- 약관이 화면·문구·운영 방식을 그대로 베끼는 것을 금지하므로, 이 문서는 기능과 구조만 적고 디자인이나 문구를 그대로 가져오지 않는다.

## 2. 기능 목록

### 2.1 매매 방식

- 유저 간 호가창 매매. 24시간 연속 거래.
- 주문 유형: 지정가, "최대한 빠르게"(시장가). 주문 화면에 "주문"과 "대기"(미체결) 탭이 있다.
- 호가 단위: 13만원대 종목에서 1,000원. 호가창의 각 가격 옆에 기준가 대비 등락률을 같이 보여준다.
- 수량 입력 보조: −/+ 버튼, 주문 가능 금액의 10%·25%·50%·100% 버튼.
- 주문 전 미리보기: 현재 평균 단가와 "구매 후 평균" 단가, 총 구매 금액.
- 약관상 주문 상태: 전부 체결, 일부 체결, 대기, 취소, 거절, 만료, 정정. 지정가 주문에 만료가 있다.
- 변동성 완화장치(VI)가 있다. 기준·지속 시간은 공개하지 않는다.
- 관리자 유동성 주문: 운영자가 유동성을 채우려고 주문을 낼 수 있다고 유의사항에 적혀 있다.
- 관리종목: 거래대금이 적은 LPL 종목은 한시적으로 관리종목으로 지정해 종목마다 정한 가격 범위 안에서만 거래하게 했다.

### 2.2 가격 결정

- 시작 가격: LCK는 방송에서 발표한 공시가격, LPL은 모두 100,000원으로 똑같이 시작했다.
- 이후 가격은 유저 체결로 움직인다.
- 방송 공시가 나오면 서비스 가격과 거래 가능 범위를 조정한다("가격 리셋"). 즉 외부 기준가가 주기적으로 가격을 끌어당기는 구조다.
- 관찰: T1 체결 내역에 550,000원 체결 다음 132,000원 체결이 이어지는 구간이 있다. 공시 반영 리셋이나 비정상 거래 정정으로 보이지만 어느 쪽인지는 확인하지 못했다.

### 2.3 배당·보상

- 경기 결과에 따른 배당은 없다. 종목 화면에 "대진"(다음 대진, 과거 대진, 스코어)이 있지만 정보 표시용이다.
- 가치의 기준은 방송 공시가격 하나다. 방송이 쉬면 가격을 끌어당길 기준이 없다.

### 2.4 재화 획득

- 시작 자산 지급(현금 + 팀별 5주).
- 랜덤 주식 이벤트: 오픈 기념, 무기한 진행. 버튼을 누르면 랜덤 종목 1~5주를 준다. 친구를 초대하면 추가 뽑기 기회.
- 광고 시청, 글쓰기, 출석 같은 반복 보상은 없다.

### 2.5 랭킹

- 상단: 방송 출연진 랭킹 카드. 출연진별 평가금, "지난 방송보다" 변동, 작은 추이 차트. 방송 속 투자(시작 자산 200만원, 실시간 거래 불가)라 사이트 투자와 다르다고 밝힌다.
- "내 랭킹": "순위표에 공개", "포트폴리오 공개" 두 개의 공개 토글. 공개하지 않은 유저는 "비공개 유저"로 이름·수치를 가린다.
- 탭: 통합, 스트리머, 일반 투자자.
- 정렬: 평가금 순, 7일 실현수익 순, 총 실현수익 순.
- 열: 순위, 닉네임, 주요 투자 종목, 평가금, 7일 대비 등락률, 7일 거래대금, 추이 차트.
- 유저 공개 프로필 페이지(`/users/u-…`)가 있고 sitemap에 수백 개가 실려 있다.
- 관찰: 상위 평가금이 8억원대로 시작 자산(200만원)의 약 400배다. 수익률이 아니라 평가금 기준이라 일찍 들어와 시세를 크게 움직인 계정이 위에 고정된다.

### 2.6 알림

- 상단 종 아이콘, `/notifications` 화면.
- 소개 화면 예시로 보면 체결 알림("KT 2주 판매 성공"), 보유 종목 등락 알림("내가 보유한 HLE가 5.2% 올랐어요"), 읽음 표시가 있다(추정).

### 2.7 공지

- 분류: 전체, 서비스 안내, 시스템 안내. 작성자는 운영자.
- 6건(2026-05-03 ~ 05-11): LCK·LPL 마켓 오픈, 주문 속도 개선, 초기 자산 변경, 치지직 스트리머 로그인 추가, 비정상 거래 탐지 및 조치.

### 2.9 법적 고지

- 화면 하단에 상시 고지: 팬 프로젝트·비공식·비영리, 모든 거래는 가상, 재화는 다른 사람과 거래할 수 없고 가치가 없음, 정보 오류 면책, 리그·라이엇·팀·네이버 상표권 표시.
- 투자 유의사항 페이지(9개 절): 실제 투자 상품이 아님, 정보는 참고용, 판단 책임은 이용자, 가격과 체결은 변동 가능, 기능별 유의사항(주문, 방송 공시, VI, 관리자 유동성 주문), 외부 서비스와 권리, 오류·중단 가능성, 과몰입 주의, 문의처.
- 이용약관 19조: 서비스 성격, 계정, 제한적 이용 허락(스크래퍼·봇 금지, 화면·문구·운영 방식 복제 금지), 가상 거래와 데이터(운영상 필요 시 주문·체결·잔고·랭킹을 보정·초기화할 수 있음), 사용자 입력 콘텐츠, 금지 행위, 부정 이용 대응, 이용 제한 등.
- 계정 삭제 시 대기 주문은 취소하고, 과거 주문·체결 원장은 개인 식별자를 지운 익명 데이터로 남긴다.
- 구버전 화면·API 요청은 정합성을 위해 차단할 수 있다고 명시.

- T1의 마지막 체결은 2026-09-06이다.

## 3. 화면 구성과 UX

### 3.1 공통

- 토스증권과 비슷한 흰 배경, 큰 숫자, 빨강(오름·구매)·파랑(내림·판매).
- 상단 메뉴: 홈, 리그별 모아보기, 랭킹, 내 계좌. 오른쪽에 알림 종과 로그인 버튼.
- 용어를 쉽게 바꿨다: 매수/매도 대신 "구매/판매", 시장가 대신 "최대한 빠르게", 미체결 대신 "대기", 매도 잔량 대신 "판매대기".

### 3.2 홈

1. 이벤트 배너(랜덤 주식 이벤트).
2. "예정된 경기" 가로 슬라이드. 오른쪽 위에 리그별 장 상태 칩("LCK 장 열림", "LPL 장 열림", "LEC 추가 예정").
3. 탭 "실시간 차트" / "지금 뜨는 팀".
4. 종목 표: 순위(7일 거래대금 순), 팀(로고·약칭·리그·이름), 다음 대진, 현재가, 24시간 등락률, 7일 거래대금, 거래 비율(구매:판매 비율을 막대로).

### 3.3 리그별 모아보기

- "리그별 상승과 하락" 슬라이드 + 리그 탭(LCK, LPL, LEC) + 홈과 같은 종목 표.

### 3.4 종목 화면

- 머리: 리그, 팀 로고·이름, 현재가(숫자 롤링 애니메이션), 24시간 대비 변동, 오른쪽에 다음 대진 "vs".
- 차트: TradingView 차트. 기간 분·일·2일·3일·주·월, 캔들/영역 차트 전환.
- 호가: 가격 + 기준 대비 %, 아래에 판매대기·구매대기 합계. 호가를 누르면 주문 가격으로 들어간다(버튼으로 되어 있음).
- 체결 내역: 시각, 가격, 수량.
- 주문 패널(오른쪽 고정): 주문/대기 탭, 판매/구매 토글, 지정가/최대한 빠르게, 가격 ± 버튼, 수량 ± 버튼, 10/25/50/100%, 평균·구매 후 평균, 총 구매 금액, 큰 구매 버튼.
- 아래 탭: "내 주식"(보유, 주문 내역) / "대진"(다음 대진, 과거 대진, 더보기). 대진에는 **"결과 가리기"** 스위치가 있어 경기 결과 스포일러를 숨길 수 있다.
- 페이지 제목에 현재가가 들어간다(예: "T1 | 134,000원 (0.0%)"). 브라우저 탭과 검색 결과에서 시세가 보인다.

### 3.5 소개 화면

- 휴대폰 목업 + "카카오로 3초만에 시작하기" 버튼을 위·아래 두 번.
- "뭐가 다른가요?" 절에서 알림 카드 예시로 실시간 거래 경험을 보여준다.

### 3.6 모바일

- 소개 화면 목업이 모바일 화면(차트·호가·내 주식·대진 탭)이라 모바일 웹을 우선으로 만든 것으로 보인다. 별도 앱은 보이지 않는다. 실제 모바일 화면은 확인하지 않았다.

### 3.7 검색 노출(SEO)

- 종목별 고정 주소(`/play/lck/t1`), 종목별 제목·설명·OG 이미지, sitemap(종목 24개는 매일 갱신, 공지, 유저 프로필), 네이버 사이트 인증.
- robots.txt로 AI 학습 크롤러는 막고 검색은 허용.

## 5. 가져올 만한 것

우선순위 순. 모두 팬차트의 기존 원칙(유저 간 호가 매매, 무료 포인트, 정합성)과 충돌하지 않는다.

1. **알림 센터 (체결·배당·보유 종목 급등락).** 지금은 화면을 보고 있을 때만 토스트로 안다. 체결과 배당 지급은 이미 서버에 이벤트가 있으므로 알림 테이블 하나와 종 아이콘으로 붙일 수 있다. 나중에 모바일 앱 푸시로 그대로 이어진다.
2. **"구매 후 평균" 미리보기.** 주문 패널에서 체결되면 평균 단가가 어떻게 바뀌는지 보여준다. 계산은 클라이언트에서 끝나고, HTS다운 경험을 준다.
3. **경기 결과 가리기.** 팬차트는 경기 배당이 핵심이라 일정·결과를 많이 보여주는데, 녹화로 보는 팬에게는 스포일러다. 계정 설정이 아니라 화면 스위치 하나로 충분하다.
4. **랭킹 공개 설정.** "순위에 이름 공개"와 "보유 종목 공개"를 나눠 고르게 한다. 개인정보 부담을 줄이고, 공개한 사람끼리 포트폴리오를 구경하는 재미가 생긴다.
5. **투자 유의사항 페이지.** 가상·무가치·과몰입 주의·데이터 보정 가능성을 한 페이지에 모은다. 금융권 포트폴리오로서 "고지 의무"를 챙겼다는 근거가 된다. 장문은 이 페이지에만 두고 화면에는 링크만 둔다(UI 텍스트 방침과 맞음).
6. **거래 비율 막대, "지금 뜨는 팀" 탭.** 홈 시세 표에 체결 매수·매도 비율이나 급등 순 정렬을 더하면 정보 밀도가 올라간다.
7. **리그별 장 상태 칩.** 점검시간·VI·숨긴 리그 상태를 짧은 칩으로 보여주면 긴 설명 없이 상태를 알린다.
8. **종목별 주소와 제목에 현재가.** 해시 라우팅을 바꾸는 큰 작업이라 모바일 앱 전환 계획과 같이 판단한다. 당장은 `document.title`에 현재가를 넣는 것만으로도 탭 전환 시 시세가 보인다.

## 6. 가져오지 말아야 할 것

1. **외부 방송 공시가로 가격 리셋.** 체결로 만든 가격을 운영자가 덮어쓰면 원장과 시세의 일관성이 깨지고, 공시 직전 정보를 아는 사람이 이득을 본다. 팬차트는 배당이라는 규칙화된 현금흐름으로 가치를 끌어당긴다.
2. **평가금 기준 랭킹.** 일찍 들어온 계정과 시세를 흔든 계정이 위에 고정된다(롤스피 상위가 시작 자산의 400배). 팬차트의 TWR + 자격 조건이 맞다.
3. **시작 자산으로 모든 팀 주식 일괄 지급.** 주식 수가 가입자 수만큼 늘어나 희석되고, 배당이 주당 고정인 팬차트에서는 배당 총액이 가입자 수에 비례해 늘어난다. 필요한 만큼만 운영자 매도(증자)로 공급하기로 한 결정(ADR 0031)과 맞지 않는다.
4. **랜덤 주식 뽑기와 친구 초대 보상.** 확률형 지급은 사행성으로 보일 수 있고, 친구 초대 보상은 다계정 농사의 통로다. 포인트 발행 통제(ADR 0008)와 이상거래 탐지의 전제를 흔든다.
5. **사후 수동 정정(거래 취소·자본 회수·계정 초기화).** 운영자가 체결을 되돌리면 대사가 깨지고 신뢰를 잃는다. 팬차트는 가격제한·VI·자기매매 방지로 사전에 막고, 정정은 원장 전표로 남긴다.
6. **"원" 표기.** 실제 화폐로 오인될 수 있다. 팬차트의 "P" 표기를 유지한다.
7. **기준을 공개하지 않는 VI·관리종목.** 사용자가 왜 주문이 막혔는지 모른다. 팬차트는 규칙서에 수치를 공개한다.
8. **방송·스트리머 의존 구조.** 롤스피는 방송이 동력이라 방송 효과가 빠지자 거래가 멈췄다. 스트리머 로그인·랭킹은 나중에 홍보 수단으로 검토할 수 있지만 핵심 구조로 삼지 않는다.

## 7. 교훈

- **콜드스타트보다 리텐션이 더 어렵다.** 롤스피는 오픈 당일 주문이 20초 밀릴 만큼 몰렸지만 넉 달 뒤 거래가 거의 없다. 팬차트는 경기마다 배당이 나오는 구조라 시즌 내내 이유가 있지만, 비시즌(KBO 겨울 등) 대책은 따로 필요하다.
- **얇은 호가에서는 가격 조작이 바로 나온다.** 롤스피의 비정상 체결과 LPL 관리종목 지정이 그 사례다. 팬차트의 가격제한·VI·이상거래 탐지가 왜 필요한지 보여주는 외부 근거로 쓸 수 있다.
- **방송 중 개인정보 노출.** 스트리머와 협업한다면 소셜 로그인 계정 정보(이메일·실명)가 화면에 나오지 않게 해야 한다.
